# Polish writing

1. Read the file the student names. Do not edit code cells or frontmatter unless asked.
2. First give feedback, **without editing**: the three biggest clarity problems (buried result, vague claims, long sentences, jargon without definition), each quoted.
3. Then offer edits as before/after pairs. Apply them only after the student says which ones they want.
4. Rules for edits:
   - Do not add facts, numbers, tools, or accomplishments. If something is vague, ask the student for the specific detail.
   - Prefer active voice, concrete verbs, short sentences, first person ("I cleaned...", not "Data was cleaned...").
   - Cut filler: "passionate", "leveraged", "utilized", "various", "very".
   - Lead with the result, then how you got there.
5. Keep any `<!-- TODO -->` comments; they mark facts only the student can supply.
